# Project 4
Este projeto consiste na criação de uma landing page de uma livraria com cafeteria integrada,em um ambiente aconchegante e moderno.

# Tecnologias utilizadas
- HTML5
- CSS3
- Metodologia BEM
- Normalize.css
- Forulário
- Google Fonts (Inter e Noto Serif)
